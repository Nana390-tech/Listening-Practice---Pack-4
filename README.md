# Listening Practice 3

Three parts: a spelling clinic that needs no recording, and two listening tasks
that use the two MP3s in this folder.

```
index.html        the whole practice — questions, marking, certificate
audio/part2.mp3   Part 2 — news report about a difficult neighbour
audio/part3.mp3   Part 3 — tour guide, day trip to Brighton
README.md         this file
```

The page looks for the recordings in an `audio` folder first, and if they are not
there it looks for `part2.mp3` and `part3.mp3` beside `index.html`. Either layout
works.

## Before the first lesson

Open **Teacher setup** in the top bar. Part 1 marks itself. For Parts 2 and 3 most
answers are already filled in, but **questions 17, 18, 19, 22 and 25** are moments
the printed answer key does not cover. Listen to the recordings once, choose the
letter for each, then **Export settings file** so you never have to do it again.
Until you set them, those five questions are simply skipped when marking and the
student is told so.

## Putting it on GitHub Pages

1. Create a new **Public** repository, for example `Listening-Practice-3`.
2. Click **uploading an existing file** and drag in `index.html`, `README.md` and
   the two MP3s (about 11 MB). Wait for them to finish, then **Commit changes**.
3. **Settings → Pages →** Source *Deploy from a branch*, branch **main**, folder
   **/ (root)**, then **Save**.
4. After a minute your link appears. Open it, go to Part 2 and press play before
   sharing it.

## What's in it

- **Part 1 — Spelling clinic (16 items).** The device reads each sentence aloud,
  the student writes the missing word. Marking is letter by letter: wrong letters
  are struck through in red and missing letters shown in amber, next to the
  correct spelling and a note on the trap. The words are the ones listening tests
  ask for again and again — accommodation, Wednesday, February, receipt,
  questionnaire, timetable, luggage, equipment, vegetarian, brochure, insurance,
  jewellery, separate — plus a surname spelled out, a price, and a booking code.
- **Part 2 — News report (8 questions).**
- **Part 3 — Tour guide (10 questions).**

Scores per part, an overall result, and a certificate. The **ع** button shows
Arabic instructions.
